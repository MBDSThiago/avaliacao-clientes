# 📋 Pesquisa de Satisfação - TudoWeb

Programa desenvolvido em Python para realizar uma pesquisa de opinião com clientes da empresa fictícia TudoWeb, coletando informações sobre o atendimento.

## 🎯 Objetivo:

O programa realiza uma pesquisa com 50 entrevistados, solicitando nome, idade e opinião sobre o atendimento:

* 🌟 **1 - Excelente**
* 👍🏽 **2 - Bom**
* 👎🏽 **3 - Ruim**

Ao final, o programa informa a quantidade de respostas **EXCELENTE** e **RUIM**.

## ▶️ Como executar:

1. Baixe este repositório.
2. Abra o projeto no Visual Studio Code ou outro editor de código.
3. Execute o arquivo Python.
4. Informe os dados solicitados para cada entrevistado.
5. Após os 50 entrevistados, o programa exibirá o resultado da pesquisa.
